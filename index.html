Atualização automática
O app lê esta lista a cada visita e adiciona só o que for novo (suas marcações são mantidas). Em branco = cards.json ao lado do app; ou cole o link "raw" do GitHub.

Alternativa manual:

Passo a passo para trazer todos os artistas (feito no computador, uma vez ou quando quiser atualizar)

  1. Salve o arquivo baixar_cartas.py numa pasta e abra o terminal nela. Instale as bibliotecas (só uma vez):
    pip install requests beautifulsoup4
  2. Teste com um artista e confira se as linhas estão certas:
    python baixar_cartas.py --teste
  3. Baixe todos os artistas (20 a 40 min; se parar, é só rodar de novo e ele continua):
    python baixar_cartas.py
  4. Quando terminar, escolha o arquivo cards.json em "Importar arquivo" abaixo.
